# Cross-lingual-LLM-gender-bias

This uses data from Zhao et al. (2018)'s winoBias dataset, and translated work by Stanovsky et al. (2019). All credits for the data go to them.
## Dataset
There are several python files present that can turn the winoBias data into the proper format for testing minimal pairs for the NLPScholar tool (Prasad & Davis, 2024). Thus all that is needed is to run the files and train the models.
